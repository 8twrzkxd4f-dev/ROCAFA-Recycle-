# Python 圓形降落傘設計介面

在終端機進入此目錄，執行：

```bash
python3 app.py
```

開啟 http://127.0.0.1:8765，按 Ctrl+C 停止。若 8765 已被占用，使用 `PARACHUTE_PORT=8766 python3 app.py` 指定其他埠。僅監聽本機，無需安裝套件或連網。

測試：`python3 -m unittest -v`。

設定傘徑、傘片數、孔徑及繩長後，可查看平面裁片與 3D 示意；更改回收質量、Cd、空氣密度、完全展開時速度與高度，Python 會計算穩態阻力及終端速度。

終端速度採 D=ρV²CdA/2 且 D=mg，A 使用名目平面面積，Cd 需與該參考面積定義一致。理想落地速度採同一 Cd 與近地密度全程固定的單傘一維模型，且傘在指定高度瞬間完全充氣；導引傘的單傘落地值不代表雙傘實際任務。目標速度為比較用假設，不代表已知競賽驗收標準。

## 動態模型與 V&V（新增）

導覽列可切換到 1D／6DOF、CFD／FSI 準備及實測比對。先選模型與參數，按「執行動態模擬」。更改參數後舊圖表會標示過期。原有的單傘穩態計算與本區設定分開；按「載入上方雙傘裁片面積」將裁片尺寸帶入雙傘模型。

- 1D：從最高點開始，模擬導引傘延遲、充氣、主傘高度觸發及分段收口。CdA 成長採 smoothstep，不是經標定的 Pflanz/Ludtke/Doherr 模型。忽略空氣附加質量、傘繩彈性與拉直衝擊。
- 6DOF：單一等效剛體，位置、速度、姿態四元數及角速度積分。水平風固定，氣動合力沿相對風反向，作用於剛體軸向偏距；角運動依對角慣量及線性旋轉阻尼求解。沒有攻角相關氣動係數，也沒有傘衣—火箭相對自由度，不能代表完整 9DOF 穩定度驗證。
- 密度：標準對流層形狀、以輸入地面密度縮放；預設海平面發射場。世界座標 Z 向上，下降速度取 -Vz；6DOF 提供垂直速度、對地合速度與漂移，勿混為一談。
- 積分：RK4，主傘高度與地面事件以二分法定位，充氣分段端點對齊；Δt、Δt/2、Δt/4 比較不是物理 Validation。峰值逐步取樣，圖表約 0.2 s 取樣。
- 導引傘是否持續作用可選。停用是主傘觸發時的理想阻力切換；保留則線性加總兩傘阻力，皆未解傘間干擾。

## CFD / FSI

本機沒有求解器時，不生成假壓力場/應力結果。匯出 ZIP 內含名目球冠薄面 STL、JSON 設定、空白材料/投放 CSV 模板及建模流程。這是準備包，不是可直接執行的 OpenFOAM case 或 LS-DYNA deck。

先找學校 Research 授權與工作站；學生版/開源方案入口在介面及準備包。布料厚度、面密度與材料名稱會保存為「未驗證的使用者輸入」，完整經緯向、剪切、雙軸、透氣與傘繩特性仍需提供。

## 實測比對

可上傳或貼上 CSV，標頭 `time_s,force_n` 或 `time_s,speed_mps`，亦可同時有兩項。所有已列出的欄位須有值；時間嚴格遞增，最多 5000 筆/500 KB。使用本次模擬的設定重算並在重疊時段線性插值，輸出 RMSE、MAE、偏差與疊圖。範例單元測試中的合成資料只檢查演算法，不是實驗證據。

網格 CSV 使用 `h_m,cd`，至少三種網格尺寸；報告相對變化，不自動宣稱網格獨立，也不冒充 GCI。未提供量測不確定度與事先定義的門檻，沒有「驗證通過」結果。

3D 球冠與動畫仍為幾何示意。動態模型輸出氣動合力，不等同實測繫帶峰值或 snatch force；物理模型狀態為未標定。
