# 圓形雙傘三維概念模型

單位：公尺（OBJ 本身不儲存單位）；Y 軸朝上。匯入 Blender 等 3D 軟體時請按公尺解讀。

| 模型 | 內容 |
|---|---|
| parachute-compare.obj | 主傘與導引傘同尺度並排比較，非雙傘實際飛行連接配置 |
| parachute-main.obj | 主傘、匯集環、示意吊帶、火箭外形 |
| parachute-drogue.obj | 導引傘、匯集環、示意吊帶、火箭外形 |

主傘：平面名目面積 6.05 m²、名目直徑約 2.775 m、12 條傘繩、有效繩長 3.45 m、平面名目中央孔 140 mm。

導引傘：平面名目面積 2.12 m²、名目直徑約 1.643 m、8 條傘繩、有效繩長 2.05 m、平面名目中央孔 80 mm。

傘面使用球冠形狀示意，子午線長度按平面半徑建立，球冠角 1.1 rad。展開後傘緣直徑約為名目直徑的 0.810 倍；此比例為幾何示意參數，不是實測充氣形狀。模型沒有求解布料周向變形、孔口實際形變、流固耦合、阻力係數、充氣時間或開傘峰值載荷。展開滑桿控制視覺形狀，不對應實際時間與高度。

火箭外形使用全長 3.098 m、直徑 0.152 m；頭錐、尾翼、0.65 m 吊帶及連接點為配置示意，非施工尺寸。尚未建立分離艙段、雙傘相互干擾、傘袋與解除裝置。

OBJ 中傘面為三角網格，傘繩為線段（不是具厚度實體），適合查看與後續建模，不能直接當作布料裁片、有限元素網格或可列印實體。

現階段：幾何模型完成，實際回收質量、打包空間及開傘動態載荷待確認。
